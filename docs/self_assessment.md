# 批判性自我评估 — G14（模板，150–200 词）

> 规则：点名两个真实弱点并给出可信的补救方案。语气自信与否不是标准。

## 弱点 1：L3 零空间分析不够深入

我们发现 A 的零空间为 8 维，但只报告了其存在和正交性，没有逐一解释 7 个额外零模式的物理来源（64 位置 × 2 取向的探针几何如何导致这些盲区）。补救：将零模式按空间频率分类，与探针位置覆盖图对比，说明哪些是"每位置两次测量冗余"造成的；若时间允许，从 64 个放置坐标直接构造探针矩阵验证零空间维数。

## 弱点 2：L2 的 E_F 轨迹在归一化空间中分辨率有限

轨迹在 |E_F| < 0.01 eV 区域出现大量平台（相邻索引分配同一模型点），因为 400 点 E_F 网格在此处过于稀疏（间距 ≈0.0004 eV，但归一化对空间在 R_H→0 处高度压缩）。补救：对中性点附近做局部加细网格（保持与数据生成器一致的全局网格做主结果，局部网格只用于报告分辨率极限）；同时在 bootstrap 中报告该区域的 16–84% 带宽，如实说明"亚 0.01 eV 漂移不可分辨"。
