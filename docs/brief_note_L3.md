# L3 Checkpoint 简要记录 — G14

**问题**：晶圆哪里不均匀？探针能分辨什么？晶圆是否通过 Session 3 公布的规格（PASS 当 max|m| ≤ 0.030，参考电导率的 3.0%）？

## 方法

- 文件检查：A 形状 (128, 100) ✓；d 形状 (3, 128) ✓；每行和最大 1.67×10⁻¹⁶ < 1×10⁻¹¹ ✓。
- **奇异值检查（重要发现）**：A 的秩为 92，零空间为 **8 维**——除常数模式（探针盲区）外还有 7 个高频不可恢复模式。指南只显式提到常数模式；本次检查发现额外零模式均为高频棋盘状结构（附方法图）。
- 重建：一阶差分矩阵 L（180×100）；投影掉常数模式 P=I−11ᵀ/100；Tikhonov 正则化，η₀=1×10⁻²‖A‖₂²/‖L‖₂²=1.331×10⁻³；`lstsq` 求解后强制零均值（|mean|=6.9×10⁻¹⁶）。
- **η 的选择（差异原则）**：η₀ 处的残差 ‖d−Am‖ = 2.163×10⁻⁴ = **12.80 × 重复噪声范数**（1.690×10⁻⁵），即 η₀ 是"光滑参考重建"而非与噪声匹配的解。指南允许在噪声给出明确理由时另选值，故取**残差仍与重复噪声一致的**最大 η：**η = 5.7×10⁻² η₀**（残差 = 1.00 × 噪声范数）。该值落在指南扫描区间 {0.01, 0.1, 1, 10, 100}×η₀ 的**内部**（L 曲线拐点处，方法图已标注）。
- **趋势分离与特征定义（关键）**：晶圆同时存在**整片平面梯度**与**局域缺陷**。平面趋势的极值必然落在图边界，因此不可能是"缺陷/特征"。按指南"把相邻像素合并为一个特征、而不是把每个像素都报成一个缺陷"，特征取自**去平面趋势后**的图（半峰判据合并相邻像素）。
- 分辨率：注入中心像素与离轴像素 (2,2) 的单位点源，同 η 同求解器重建，正瓣加权 σ²=Σ(w r²)/(2Σw)，FWHM=2.355σ。
- 检测限：三扫描得每通道 σ_j；500 个噪声向量（种子 20260921，零均值正态、σ_j），重建后 max|m_noise| 的 95 百分位。

## 结果

- **晶圆级梯度**：−3.30×10⁻³ / pitch（x）、−5.05×10⁻³ / pitch（y），幅值 **6.03×10⁻³ / pitch**；去趋势后残余峰值 0.0179。
- **局域特征（均在内部）**：

| 符号 | 幅度 | 位置 (x, y) | 像素 | 合并像素数 |
|---|---|---|---|---|
| 正 | **+0.0179** | **(+0.3, +1.5)** | (7, 5) | 7 |
| 负 | **−0.0142** | **(−0.9, −0.9)** | (3, 3) | 6 |

- **主导特征严格位于图内部**（两个坐标都不在边界 ±2.7 上）。注意：直接取全图极值会得到 (−2.7,−2.7)/(+2.7,+2.7)——那是平面趋势的角点，不是缺陷（这正是先前版本的错误）。
- 分辨率：中心 FWHM 1.80 探针间距（离轴更小）→ 保守报告 **1.80 探针间距**（≈3.0 像素）。
- 检测限 δ₉₅ = **6.46×10⁻⁵**（在选定的 η 下；若用 η₀ 则为 2.36×10⁻⁵，但该重建残差达噪声的 12.8 倍）。
- 决策：a = max|m| = **0.0456**（含晶圆级趋势，指南规定 a=max|m_hat|）；a−δ₉₅ = 0.0456 > 0.030 → **FAIL（clear）**。

## 物理解释

晶圆存在横跨全片的**电导率平面梯度**（角点幅度 ≈4.5% 参考值，梯度 6.0×10⁻³ / 间距），叠加两个**局域缺陷偶极**：正缺陷（+1.8%）在 (x,y)=(+0.3,+1.5)，负缺陷（−1.4%）在 (−0.9,−0.9)，两者相距约 2.7 个探针间距。

- 平面梯度是**系统性工艺问题**（生长炉沿 x/y 的温度或气流梯度），建议检查炉内方向性分布。
- 两个局域缺陷是**局部缺陷**，各自幅度均低于 3.0% 规格；但**全图 max|m| 由梯度决定**，而规格约束整片非均匀性，故整体判 FAIL。
- 分辨率 1.80 间距意味着间距 <1.8 的细节无法分辨；零空间 7 个高频模式是探针几何的固有盲区（除常数模式外）。
- 与 L2 一致：该材料 E_F 对掺杂极敏感，故生长过程中的微小梯度即可产生可测的整片非均匀性。
