# L3 Checkpoint 简要记录 — G14

**问题**：晶圆哪里不均匀？探针能分辨什么？晶圆是否通过 Session 3 公布的规格（PASS 当 max|m| ≤ 0.030，参考电导率的 3.0%）？

## 方法

- 文件检查：A 形状 (128, 100) ✓；d 形状 (3, 128) ✓；每行和最大 1.67×10⁻¹⁶ < 1×10⁻¹¹ ✓。
- **奇异值检查（重要发现）**：A 的秩为 92，零空间为 **8 维**——除常数模式（探针盲区）外还有 7 个高频不可恢复模式。指南只显式提到常数模式；本次检查发现额外零模式均为高频棋盘状结构（附方法图）。
- 重建：一阶差分矩阵 L（180×100）；投影掉常数模式 P=I−11ᵀ/100；Tikhonov 正则化，η₀=1×10⁻²‖A‖₂²/‖L‖₂²=1.331×10⁻³；`lstsq` 求解后强制零均值（|mean|=6.9×10⁻¹⁶）。
- η 敏感性（L 曲线，0.01×~100×η₀）：地图最大变化仅 1.9×10⁻³（相对 max|m|≈4%），η₀ 参考值稳定，无更换理由。
- 分辨率：注入中心像素与离轴像素 (2,2) 的单位点源，同 η 同求解器重建，正瓣加权 σ²=Σ(w r²)/(2Σw)，FWHM=2.355σ。
- 检测限：三扫描得每通道 σ_j；500 个噪声向量（种子 20260921，零均值正态、σ_j），重建后 max|m_noise| 的 95 百分位。

## 结果

- **地图**：以**对角梯度**为主——左下角 (x,y)=(−2.7,−2.7) 处 +0.0427，右上角 (+2.7,+2.7) 处 −0.0451，单调下降；无孤立点缺陷。
- 特征：正极值 +0.0427 @(−2.7,−2.7)；负极值 −0.0451 @(+2.7,+2.7)（幅度 ≈4.5% 参考电导率）。
- 分辨率：中心 FWHM 1.44 探针间距；离轴 1.30 → 保守报告 **1.44 探针间距**（≈2.4 像素）。
- 检测限 δ₉₅ = **2.36×10⁻⁵**（噪声极小，三扫描几乎一致）。
- 决策：a = max|m| = 0.0451；a−δ₉₅ = 0.0451 > 0.030 → **FAIL（clear）**。

## 物理解释

晶圆存在横跨全片的**电导率对角梯度**（~4.5% 参考值），最可能源于生长过程中沿对角方向的掺杂/载流子浓度梯度（与 L2 中 E_F 大范围漂移一致——该材料 E_F 对掺杂极敏感）。这是**系统性工艺问题**而非局部缺陷：建议检查生长炉的温度/气流对角分布。分辨率 1.44 间距意味着 <1.4 间距的精细结构无法分辨；零空间的 7 个高频模式是探针结构的固有盲区。
